# FreeInference agentic trace, visualized

A static website for exploring the FreeInference agentic trace, the dataset of
the paper *From Requests to Sessions: A Large-Scale Characterization of
Human-Driven Agentic Workloads*. It draws the paper's figures for any weeks
you choose and opens any session to show how its context grew, what it
cached, which tools it called and which subagents it spawned.

Everything runs in the browser. The site is a folder of HTML pages, ES
modules and Parquet files; DuckDB-WASM queries the Parquet files over HTTP
and Observable Plot draws the results. There is no server and no build step.

## Pages

| Page | File | What it shows |
|---|---|---|
| Explore | `index.html` | Weekly trends, headline numbers, distribution cards and a searchable table of the selected weeks' sessions |
| Paper figures | `figures.html` | The paper's figures, redrawn for the selected weeks and scope |
| Session | `session.html` | One session and its subagents: a bar per request, context over time, and a timeline per agent |
| About | `about.html` | Definitions, how the data were built, and links |

The chosen weeks, month and scope live in the URL (`?month=2026-07&scope=All`),
so any view can be shared as a link.

## Running it

```bash
make setup    # a virtual environment with the pipeline's package and the test tools
make data     # site/data/ from the release: four Parquet files and weeks.json
make serve    # http://localhost:8000
make test     # the Python tests and the node tests
make deploy   # publish site/ as the only commit of gh-pages on origin, force-pushed (git 2.42 or later)
```

`make data` reads the release and the cache simulation built by the pipeline
repository, `../freeinference-agentic-pipeline`. To build from a downloaded
copy of the dataset instead:

```bash
make data RELEASE=~/freeinference_agentic_trace/release SIMULATION=~/freeinference_agentic_trace/simulation
```

## Layout

```
README.md          this file
CONTRIBUTING.md    the rules, the patterns, and how to add a query, a figure or a page
Makefile           setup · data · serve · test · deploy
deploy.sh          what make deploy runs: copies site/ onto an orphan branch and force-pushes it
pyproject.toml     Python 3.12; the pipeline's package, pyarrow, pandas; pytest and duckdb for tests
package.json       sets ES modules for node --test; no dependencies
site_data/         builds site/data/ from a release
site/              exactly the files that are deployed
  *.html           one file per page
  style.css        tokens, layout and components
  js/shared/       the database, the selection, the libraries, formatting, the table, the layout
  js/pages/        one module per page
  js/figures/      one module per figure section
  js/session/      the Session page's views
  queries/         one .sql file per chart or table, grouped by page
  data/            generated by make data; never tracked
tests/             Python tests, and node --test files for pure JavaScript
openspec/          the specifications and the changes that built the site
```

## Where the numbers come from

Every definition the site shows (session, turn, scope, wait, cached share,
idle gap) is computed by the pipeline's own functions when `make data` runs.
The browser only filters, counts, sums and takes quantiles. With every week
selected and the Agentic scope, a figure's numbers equal the paper's.

- Dataset: https://huggingface.co/datasets/harvardMadsys/freeinference_agentic_trace
- Pipeline: https://github.com/HarvardMadSys/freeinference_agentic_trace
