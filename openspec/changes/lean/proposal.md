# Change: lean

## Why
After `simplify` the site is about 8,400 lines of JavaScript and 9,000
of tests for one landing page and one session page. Three things keep
it that size: 31 figures with 29 draw functions for about seven chart
shapes, each restating the frame, ticks, labels and tooltip; a sessions
table that still reads three generations of URL keys no public link
ever used; and tests that pin markup detail by hand while nothing
checks the whole page a visitor sees. Comments are a fifth of the code,
many of them narrative. A maintainer who did not write this should meet
seven chart kinds and a list of entries, one URL format, and one test
that says whether the page changed.

## What changes
Nothing a visitor sees or can do changes.

- **Snapshot tests first.** The gate script of `simplify` becomes a
  tracked test: for each of nine page states, one checksum per chart,
  table, legend and text block, in `tests/snapshots/`, compared by
  `make test` in headless Chromium, regenerated by `make snapshots` when
  a change is meant. The unit tests that pinned markup go once the
  snapshots cover them.
- **Figures as entries over chart kinds.** Seven kind functions in
  `js/charts/` (CDF lines, stacked bars by week, quantile ranges,
  histogram, ranked areas, lines with a knee, donut), each taking
  options. A figure is an entry: query, kind, columns, labels, the four
  texts, and at most one `annotate` hook for a paper-specific callout.
  The runner in `figure_sections.js` reads two fields, `kind` and
  `query`, instead of a set of flags.
- **One URL format.** The sessions table reads and writes
  `months`, `harnesses`, `model`, `min`, `search`, `sort` and `page`;
  the `weeks=`, `month=` and `scope=` keys and the old anchors go, with
  their rewriting and tests.
- **Comments say what, in a few lines.** CONTRIBUTING gets the rule: a
  module header is at most eight lines, an export's docstring one to
  three; reasoning that is history is not written. The pass applies it
  to the modules the other tasks touch.
- **The specs squashed** into three files and the archive removed, as
  `simplify` decided.

## Before and after
| | After `simplify` | After `lean` |
|---|---|---|
| Figure modules (`figures/`, `simulation/`, `comparison/`) | about 2,500 lines, 29 draw functions | about 1,400 lines, 7 kinds |
| Sessions table stack | about 900 lines | about 650 lines |
| JavaScript under `site/js` | about 8,400 lines | about 5,500 lines |
| Tests | about 9,100 lines | about 6,000 lines, plus the snapshots |
| What a visitor sees | | the same |

## Impact
- Specs: `explore-page` (a figure is an entry over a kind),
  `week-selection` (one URL format), `site-repository` (snapshot tests,
  the comment rule, then the squash).
- Code: `js/charts/` new, the figure modules rewritten as entries,
  `figure_sections.js` and `charts.js` reduced, `sessions_filter.js`
  and `sessions_table_state.js` reduced; `tests/snapshots/` new; the
  markup tests removed.
- Data: none.
